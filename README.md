# Student Management System 🎓
A Full Stack Java application for managing student registries with real-time database synchronization.

### 🚀 Tech Stack
* **Backend:** Java 21, Spring Boot 4.0.5, Spring Data JPA.
* **Database:** MySQL 8.0.
* **Frontend:** HTML5, JavaScript (Fetch API), Tailwind CSS.

### ✅ Working Outcome
**1. Registry Interface:** Students are registered via a modern web form.
